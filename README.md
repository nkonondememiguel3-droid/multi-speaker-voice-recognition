# This project is my implementation of a multi-speaker voice recognition system in python.

This is a project for learning purpose that includes itself in my AI learning journey.

## Steps involved in the completion of this project:
    - [] Phase A: signal processing
        1. Ingestion & format normalization
        2. Voice activity detection (VDA)
        3. Mel-Spectrogram extraction
        4. SVD-based spectral denoising
        5. CMVN (Cepstral Mean & Variable Normalization)
        6. Data augmentation pipeline
    ~~- [] Spark clustering for data preparation~~
    - [] Phase B: Encoder (Neural network)

## Things to do when cloning this project:

When you clone this project, create a `datasets` directory and put all of your audio there.
